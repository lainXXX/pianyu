# 产品架构

## 数据流

浏览器 → HTTP 接口 → 任务队列 → 下载／识别／质检 → 原稿及阅读稿 → 风格生成／来源校对 → 本地文字与图片渲染 → 历史。

`server.create_app()` 是应用组装入口，配置、厂商、浏览器登录和日志由独立模块提供。任务与接口仍保留既有入口；本次不搬动所有算法文件，避免大范围改路径造成不必要回归。

## 模块职责

| 模块 | 对外入口 | 维护时关注点 |
| --- | --- | --- |
| `configuration` | `AppPaths`、`SettingsStore` | 所有配置路径、迁移、原子替换；配置与运行数据分开 |
| `api.models` | Pydantic 请求体 | HTTP 字段与校验，不放算法或持久化逻辑 |
| `api.settings` | `register_settings` | 设置、厂商选项、默认值与诊断接口 |
| `browser_login` | `BrowserLoginManager`、`register_browser_login` | 浏览器线程、会话状态、平台 Cookie 选择与保存 |
| `providers` | `ASR_PRESETS`、`LLM_PRESETS` | 厂商官方链接和可编辑默认值；不创建已配置服务 |
| `engines`、`llm` | Registry、LLMRegistry、ChatClient | 地址校验、凭证选择、协议客户端 |
| `pipeline` | `run` | 视频处理流程；进度回调供 Web 和命令行共用 |
| `outputs`、版式存储 | 按 id 读写与绑定 | 风格决定可用版式，反向绑定一致性 |
| `observability` | `EventLog` | 日志轮转、字段白名单、请求关联；不收集业务正文 |

## 扩展方式

- 增加兼容厂商：确认现有协议支持后，在 `providers.py` 增加预设和官方链接，并补默认值与表单选择测试。厂商预设仅是起点，模型名和地址可编辑。
- 增加识别协议：实现现有 `transcribe(wav)`、`name` 与计费／时间戳属性，在 `engines.py` 注册构造和字段；保持流水线不感知厂商细节。不能把仅支持聊天的兼容地址直接宣称支持识别。
- 增加平台登录：在 `browser_login.PLATFORMS` 配置官方登录页、允许域和登录标记，补伪域、过期、取消及真实隔离浏览器用例。仅使用片语专属 profile，不读取用户系统浏览器资料。
- 增加风格：沿用输出类型的数据契约；公共行为进入全局规则，风格只写组织与表达差异。自定义风格不覆盖内置项。
- 增加设置：确定所属文件，再扩展存储与 HTTP 校验。不要把密钥混入服务列表，或把提示词写回运行设置。

## 状态与持久化

配置是用户资产；`config/` 中服务、密钥、规则、版式与 Cookie 分开保存。配置写入使用临时文件及原子替换，减少中途失败造成截断。迁移只复制、不删除、不覆盖，真实旧配置保留供回退；新目录修改后旧副本不再同步。

`work/jobs/` 是任务记录及产物，`work/browser-profiles/` 是网页登录的独立持久会话，缓存由下载与识别模块管理。日志在 `logs/`，不与业务文件混放。

浏览器登录状态为 `opening → waiting → connected`，异常进入 `failed`，用户取消进入 `cancelled`。页面定时查询状态；成功后自动保存 Netscape Cookie。已保存 Cookie 只代表有登录信息，平台失效或风控仍可能要求重新登录。

## 验证原则

配置迁移、凭证隔离、登录域限制和日志隐私用定向模块／接口测试。页面新增、编辑、官方跳转、网页登录等待／取消／失败、默认值与目录可见性使用实际 Edge 点击验收。网站登录机制通过阻断外网的合成页面点击验证提取与保存；真实站点可能有验证码、扫码或登录限制，需人工在打开的官方页面完成。
